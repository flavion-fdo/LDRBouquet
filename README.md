# 🌸 Petal & Quill — Long-Distance Bouquets & Secret Notes

An interactive, hand-drawn virtual bouquet studio designed specifically for long-distance couples. Assemble real flower blooms, attach secret heartfelt love notes to each petal, customize romantic airmail packaging with distance badges, and share an interactive digital gift directly with your loved one across the miles.

---

## ✨ Features

- 🌿 **Real Hand-Drawn Blooms**: Rose, Tulip, Sunflower, Daisy, Lavender, Peony, Lily, Cherry Blossom, Hydrangea, and Bluebell.
- 💌 **Hidden Secret Notes**: Write personalized notes for each flower. Each note reveals itself with a typewriter animation when your partner clicks the blossom.
- ✈️ **Airmail Dedication Tags**: Specify *To*, *From*, *Miles Apart / Distance*, and a dedication message.
- 🎨 **Packaging & Ribbon Customization**: Airmail Kraft Cone, Romantic Satin Silk, Vintage Love Letters, Glass Crystal Vase, and Starlit Midnight.
- 🔗 **Interactive Sharing**: Encodes the entire bouquet state and secret notes into a shareable URL hash.
- 📱 **One-Click Social Sharing**: Direct sharing to WhatsApp, Telegram, Email, or instant copy formatted for iMessage, Instagram DM, and Discord.
- 🎁 **Recipient Airmail Presentation Mode**: When your partner opens the link, they experience a full-screen gift opening with ambient falling petals and petal-by-petal secret note discovery.
- 🔁 **Reply Bouquet**: Loved ones can click "Send One Back!" after reading all notes to return the love with their own bouquet.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/flavion-fdo/petal-and-quill.git

# Navigate into the project folder
cd petal-and-quill

# Install dependencies
npm install

# Run local development server
npm run dev
```

### Build for Production

```bash
npm run build
```
