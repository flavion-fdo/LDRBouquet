# 🌸 Petal & Quill — Long-Distance Bouquets & Secret Notes

An interactive, hand-drawn virtual bouquet studio designed specifically for long-distance couples. Assemble real flower blooms, attach secret heartfelt love notes to each petal, customize romantic airmail packaging with distance badges, and share an interactive digital gift directly with your loved one across the miles.

---

## ✨ Features

- 🌿 **Real Hand-Drawn Blooms**: Rose, Tulip, Sunflower, Daisy, Lavender, Peony, Lily, Cherry Blossom, Hydrangea, and Bluebell.
- 🖐️ **Interactive Drag-and-Drop Placement**: Grab any flower head and move it freely around the canvas; realistic organic stems flex, curve, and follow dynamically in real time.
- 🏺 **Stems Gathered Inside the Bouquet**: Front and back paper layering ensures all stems tuck neatly inside the wrapper cone or stand submerged inside the crystal water of the glass vase.
- 📱 **Full Multi-Device Responsiveness**: Tailored layouts for smartphones, tablets, and desktops with an intuitive mobile studio switcher (`🌸 Bouquet`, `💐 Pick Blooms`, `🎀 Wrap & Tag`) and touch-drag support.
- 💌 **Hidden Secret Notes**: Write personalized notes for each flower. Each note reveals itself with a typewriter animation when your partner clicks the blossom.
- ✈️ **Custom Airmail Dedication Tags**: Specify *To*, *From*, *Miles Apart / Distance*, and dedication messages with a direct click-to-edit modal on the canvas.
- 🎨 **Packaging & Ribbon Customization**: Airmail Kraft Cone, Romantic Satin Silk, Vintage Love Letters, Glass Crystal Vase, and Starlit Midnight.
- 🔗 **Interactive Sharing**: Encodes the entire bouquet state and secret notes into a shareable URL hash.
- 📲 **One-Click Social Sharing**: Direct sharing to WhatsApp, Telegram, Email, or instant copy formatted for iMessage, Instagram DM, and Discord.
- 🎁 **Recipient Airmail Presentation Mode**: When your partner opens the link, they experience a full-screen gift opening with ambient falling petals, celebration confetti, and petal-by-petal secret note discovery.
- 🔁 **Reply Bouquet**: Loved ones can click "Send One Back!" after reading all notes to return the love with their own bouquet.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/flavion-fdo/LDRBouquet.git

# Navigate into the project folder
cd LDRBouquet

# Install dependencies
npm install

# Run local development server
npm run dev
```

### Build for Production

```bash
npm run build
```
